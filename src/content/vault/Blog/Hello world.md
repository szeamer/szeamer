## Writing a new post

Make a new note in the `Blog` folder of the `szeamer` folder in Obsidian. The note's name is
the title, and it becomes the URL, so `First frost` is served at `/blog/first-frost/`.

Give it a `date` property. A post with no date, or with `draft` checked, stays
unpublished.

Everything else is ordinary markdown — **bold**, *italic*, [links](https://astro.build),
lists, quotes and fenced code blocks all work. Paste images straight in.

> Posts appear on the front page automatically, newest first.
